《极速霓虹：Evolution Pro Max》 是一款充满动感的赛博朋克风街机避障游戏。在绚丽的粒子流和震动的电子节拍中，玩家将操纵霓虹核心穿越无尽的数据风暴，迎击强大的非法程序拦截（Boss），不断进化自身的防御与攻击模块。
🎮 游戏核心特性
1. 动态波次系统 (Infinite Waves)
游戏不仅有难度的线性递增，更具备独特的波次过渡仪式感。
平滑节奏：随波次增加，背景粒子会加速流动，进入“超空间跳跃”视觉。
过渡保护：每波结束会有短暂的数据同步期，清理全场障碍，给玩家喘息之机。
2. 领主挑战 (Epic Boss Fights)
每 5 个波次将遭遇一次强大的 领主程序 (Boss)。
多阶弹幕：Boss 会散射高能红色代码，考验玩家走位。
数据核心反击：通过收集战场随机掉落的白色数据核心，对 Boss 造成致命伤害。
3. 技能实验室 (The Skill Lab)
收集霓虹币，在实验室中永久提升你的属性：
磁场强度 (Magnet)：自动吸取远处的数据与货币。
防御模块 (Shield)：增加紧急避震时长，容错率大幅提升。
充能速率 (Fever)：更快进入无敌超载模式，碾碎一切。
数据溢出 (Gold Bonus)：倍增每次冒险获得的财富。
4. 视觉盛宴 (Neon VFX)
毛玻璃界面 (Glassmorphism)：圆滑精致的 UI 交互，沉浸感十足。
动态粒子拖曳：每一帧的移动都带有彩色残影特效，流畅如丝。
双语支持：一键切换 中/英 系统界面。
🕹️ 如何操作
平台	操作方式	说明
PC 端	鼠标移动	控制霓虹核心跟随鼠标
移动端	单指滑动	核心将跟随你的手指位置
红色方块：系统阻断程序（障碍物），必须闪避。
黄色球体：霓虹币，用于实验室升级和皮肤解锁。
蓝色/绿色球体：体型变大或缩小的状态加成。
紫色能量：填满能量条后进入 超载模式 (OVERLOAD)，此状态下无视障碍且得分倍增。
🛠️ 技术栈
渲染引擎：原生 HTML5 Canvas API (无任何第三方库，性能最优化)。
状态管理：原生 JavaScript 闭包对象。
本地存储：LocalStorage（自动保存你的最高分、金币及技能等级）。
UI/UX：现代 CSS 变量 + 30px 高圆角矩形 + 多重高斯模糊。
